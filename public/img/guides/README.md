# Captures d'écran des guides

Images facultatives affichées derrière le lien discret « Voir une capture » sous une étape.
Le lien n'apparaît que si le fichier existe : le serveur liste au démarrage les images présentes
ici et les transmet à la page via `/api/config` (champ `shots`).

- Formats acceptés : `.png` (recommandé), `.jpg`, `.webp`. Largeur conseillée : 1200 à 1600 px,
  recadrée sur la fenêtre utile, sans données personnelles réelles (utiliser test@example.com).
- Après ajout : `docker compose up -d --build` (les fichiers sont intégrés à l'image).
- Pour une nouvelle capture : ajouter `shot: 'dossier/fichier.png'` (et éventuellement
  `shotCaption: '…'`) à l'étape concernée dans `public/js/guides.js`.
